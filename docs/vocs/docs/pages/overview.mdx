# CreditChain Overview

CreditChain is a Rust-first, Reth-based public EVM chain for AI-native financial infrastructure. The node binary is `creditchaind`, the canonical repository is [openibank/creditchain](https://github.com/creditchainorg/creditchain), and the official website is [www.creditchain.org](https://www.creditchain.org).

CreditChain keeps Ethereum JSON-RPC and EVM compatibility as the default contract with wallets, explorers, SDKs, and operator tooling. The chain-core implementation is intentionally a shallow fork of Reth: upstream execution-client crates remain available internally, while CreditChain-owned branding, chainspecs, environments, packaging, and operator surfaces live at the project boundary.

## Design Priorities

- Preserve standard Ethereum JSON-RPC behavior and EVM semantics.
- Keep CreditChain-specific logic modular and easy to isolate.
- Make environments, genesis files, packaging, health checks, metrics, and runbooks first-class.
- Keep the path open for future protocol primitives such as identity, operator bindings, SpendPermit, attestation, AI Credit, and escrow without destabilizing the execution layer early.
