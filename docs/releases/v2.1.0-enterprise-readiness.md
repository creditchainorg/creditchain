# CreditChain v2.1.0 Enterprise Readiness Release Notes

Release focus: make CreditChain safer to publish, easier to deploy, and easier
for institutions to adapt without leaking operator-specific infrastructure.

## Highlights

- Native gas token metadata is first-class. Public CreditChain networks use
  `CCC` (`CreditChain Token`, 18 decimals).
- Enterprise forks can customize native token name, symbol, decimals, chain id,
  RPC URLs, faucet URLs, and explorer URLs from the network registry.
- Faucet supports configurable native token display metadata and returns
  `native_currency` plus `amount_base_units`.
- iWallet reads native token metadata from the CreditChain registry and formats
  balances with the selected network's decimals and symbol.
- Browser network metadata now includes native currency and explorer URLs.
- Public docs no longer include internal hostnames or private deployment notes.
- Generic Nginx edge templates replace environment-specific edge configs.

## Operator Upgrade Notes

Existing `.env` files that use `FAUCET_DRIP_AMOUNT_CCC` still work. New
deployments should use:

```dotenv
NATIVE_TOKEN_NAME=CreditChain Token
NATIVE_TOKEN_SYMBOL=CCC
NATIVE_TOKEN_DECIMALS=18
FAUCET_DRIP_AMOUNT=1
```

For enterprise forks, update all of these together before launch:

1. `deploy/shared/networks.json`
2. `genesis/*.json`
3. Browser registry mirror
4. iWallet registry mirror
5. chain stack `.env`
6. public user manual/onboarding docs
